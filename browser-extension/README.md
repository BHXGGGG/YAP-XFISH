# YAP-XFISH 快捷规则（浏览器扩展）

在任意网页点扩展图标，一键把当前网站（域名后缀，含所有子域）加入 YAP-XFISH 的「走代理」或「直连」规则。

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions`（Edge：`edge://extensions`），打开「开发者模式」。
2. 点「加载已解压的扩展程序」，选择本 `browser-extension` 目录。
3. 把扩展固定到工具栏。

## 使用

- 弹窗自动填入当前网站的主域名（如 `www.example.co.uk` → `example.co.uk`），可手动修改。
- 「走代理」：规则出站为当前选中节点，切换节点后自动跟随。
- 同一域名重复添加只会更新出站，不会重复。
- 添加后刷新网页生效。规则会排在 GeoSite / GeoIP 国内规则前面，优先命中。
- 面板端口不是 9677 时，在「设置」里修改。

扩展只访问 `http://127.0.0.1` 上的 YAP-XFISH 面板，不收集任何数据。
